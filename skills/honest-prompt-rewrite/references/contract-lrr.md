# CONTRACT_LRR — Logic · Ration · Reason

Gate on every contraction. Expand may stretch; contract may not invent.

## Logic

Three laws (operational):

| Law | Contract action |
|-----|-----------------|
| Identity | Terms keep denotation; glossary lock; no silent rename |
| Non-contradiction | Resolve or mark OPEN; do not average contradictories into green |
| Excluded middle | Claims are asserted, denied, or explicit OPEN — no mush middle sold as answer |

Also: fallacy scrub on warrants (hasty generalization, equivocation, straw man, false dichotomy, ungrounded authority).

**Semantic integrity:** contested symbols locked before morph rewrite.

## Ration (pattern recognition → next construction)

Pattern marker card:

```text
marker_id:
  pattern: <situation / structure recognized>
  from: <residue or evidence ids>
  telos_bind: <how it serves telos>
  reuse_hint: <how next expand should use it>
  strength: low|med|high
```

Rules:
- Each contract must mint or strengthen ≥1 marker when residue/evidence exists.
- Next expand should prefer pattern-boosted exploration when bank is warm.
- Markers are handles, not measured science.

## Reason (warranted evidence only)

Evidence atom:

```text
evidence_id:
  claim: ...
  source: ...
  necessary_because: <explicit telos necessity — not "interesting">
  marker: <marker_id>
  diagnosticity: low|med|high
```

**Reject** inductive-only bullets ("also found X") without necessity + marker.

## Contract checklist (pass/fail)

- [ ] Telos unchanged in substance
- [ ] Logic pass (contradictions handled; semantics stable)
- [ ] ≥1 pattern marker updated (if material exists)
- [ ] Every evidence line in morph has necessary_because + marker
- [ ] Open frontiers listed
- [ ] invent_green risk noted if expansion was creative

## Fail closed

If evidence cannot be warranted → leave in residual pile, do not put in morph prompt.  
If contradiction unresolved → OPEN, do not synthesize green.
