# Hourglass-EDC
## Full beat
```text
EXPAND
  - log queries, inclusion/exclusion
  - multi-source: academic, official data, discourse, cross-domain
  - extract findings + limitations + relevance
DISCONFIRM
  - pick leading hypothesis
  - design ≥1 query expected to hurt it if false
  - record result in ACH
CONTRACT_LRR
  - Logic scrub
  - update pattern markers
  - keep only warranted+attached evidence in morph
  - research_prompt' = telos-conditioned instrument (not note dump)
```
## Light path
```text
one focused expand → contract_LRR (abbreviated) → answer
```
Use when user wants a simple lookup.
## Stop
- No new diagnostic evidence 
- Budget 
- Leading hypotheses stable under disconfirm 
## Anti-patterns
- Expand-only then long prose 
- Contract as inductive pile 
- Skipping disconfirm 
- Llama/chat proxy as product apparatus when science path claimed
